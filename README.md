## Getting Started

### Prerequisites

- A compatible operating system
- Clang C compiler
- Visual Studio Code or another code editor

### Compile and Run

Compile the Hello World program:

```bash
clang "Basic Programs/Hello World.c" -o hello_world
```

Run the program:

```bash
./hello_world
```
